# Project Statement

## Project Title

Mini E-Commerce Order Analyzer

## Problem Statement

Small online stores need to manage products and orders and understand
their sales performance. Managing this information manually can make
it difficult to track stock, orders and sales.

This project provides a simple Python-based system to manage products,
record orders and analyze basic sales information.

## Target Users

The project is intended for:

- Small online sellers
- Students learning e-commerce management
- Small shop owners

## Scope

The project focuses on:

- Product management
- Order management
- Sales analysis
- Report generation

The project does not include online payment, real-time delivery
tracking or a web application.

## Main Features

1. Add, update and delete products
2. Search and sort products
3. Create and view orders
4. Calculate sales
5. Find the best-selling product
6. Generate reports
7. Store data using JSON files
