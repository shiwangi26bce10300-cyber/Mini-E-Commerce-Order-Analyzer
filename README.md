# Mini E-Commerce Order Analyzer

## Overview

Mini E-Commerce Order Analyzer is a simple Python console application
for managing products and orders and analyzing basic sales data.

The project is designed as a beginner-friendly Python project.

## Features

- Product Management
- Add Product
- Update Product
- Delete Product
- Search Product
- Sort Products by Price
- Order Management
- Add Order
- View Orders
- Sales Analysis
- Best-Selling Product
- Average Order Value
- Report Generation
- JSON Data Storage

## Technologies

- Python
- JSON
- File Handling
- Functions
- Lists
- Dictionaries
- Loops
- Conditional Statements

## How to Run

Install Python 3.x.

Open the project folder in terminal.

Run:

python main.py

## Data Storage

Product and order information is stored in JSON files.
